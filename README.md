# Akshat Talwar — Portfolio

A recruiter-first, responsive portfolio for a new-grad software engineer. It is a dependency-free static site with a lightweight Canvas 3D scene, accessible motion settings, and concise evidence from internships and projects.

## Run locally

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Deploy

Deploy directly to Vercel, Netlify, GitHub Pages, or any static host. No build command is required; publish the repository root.

## Edit content

- `index.html` — profile, experience, projects, skills, links
- `styles.css` — layout, responsive design, visual system
- `script.js` — 3D Canvas scene and interaction effects
- `assets/Akshat-Talwar-CV.pdf` — viewable and downloadable one-page CV
- `assets/logos/` — company marks used for employer identification (AWS, Tech Mahindra, and Grant Thornton)

Company marks are trademarks of their respective owners and are used only to identify prior employers. SVG assets are sourced from their Wikimedia Commons file pages.

Animations honor the operating system's **Reduce motion** preference.
